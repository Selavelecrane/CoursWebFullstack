Module 1 · HTML

Listes et tableaux

Deux familles de balises qui structurent des données : les listes pour énumérer, les tableaux pour présenter en grille. Attention, l'un des deux est piégeux — on verra pourquoi.

1 Pourquoi des listes ?

Dès qu'on a plusieurs choses à présenter les unes sous les autres — une recette, un menu, une playlist, une to-do — on utilise une liste.

HTML propose deux types de listes principales :

  • Les listes non ordonnées : l'ordre n'a pas d'importance (une liste de courses, un menu de navigation).
  • Les listes ordonnées : l'ordre compte (une recette étape par étape, un classement).
La question à te poser Si tu mélangeais les éléments, est-ce que ça changerait quelque chose ?
Non → liste non ordonnée (<ul>).
Oui → liste ordonnée (<ol>).

2 La liste non ordonnée : <ul>

<ul> signifie unordered list. Elle contient une suite de balises <li> (list item, « élément de liste »). 

<ul>
  <li>Pommes</li>
  <li>Bananes</li>
  <li>Cerises</li>
</ul>
  • Pommes
  • Bananes
  • Cerises

Le navigateur affiche une puce (un petit rond) devant chaque élément.

<ul>

Ouvre la liste. Contient uniquement des <li> (en HTML moderne).

<li>

Un élément de la liste. C'est ici qu'on met le texte.

</ul>

Ferme la liste.

3 La liste ordonnée : <ol>

<ol> signifie ordered list. Fonctionne comme <ul>, mais le navigateur affiche des numéros au lieu de puces. 

<ol>
  <li>Casser les œufs dans un bol</li>
  <li>Ajouter la farine</li>
  <li>Mélanger jusqu'à obtenir une pâte lisse</li>
  <li>Cuire 20 minutes à 180 °C</li>
</ol>
  1. Casser les œufs dans un bol
  2. Ajouter la farine
  3. Mélanger jusqu'à obtenir une pâte lisse
  4. Cuire 20 minutes à 180 °C

L'ordre compte : sans lui, la recette ne veut rien dire.

Peut-on changer le type de numérotation ? Oui, avec l'attribut type : <ol type="A"> (A, B, C…), type="i" (i, ii, iii…), ou start="5" pour commencer à 5. Mais on verra plus tard qu'en vrai, on change plutôt ça en CSS.

4 Les listes imbriquées

On peut mettre une liste à l'intérieur d'un <li>. C'est très utile pour les menus et les arborescences. 

<ul>
  <li>Fruits
    <ul>
      <li>Pomme</li>
      <li>Banane</li>
    </ul>
  </li>
  <li>Légumes
    <ul>
      <li>Carotte</li>
      <li>Brocoli</li>
    </ul>
  </li>
</ul>
  • Fruits
    • Pomme
    • Banane
  • Légumes
    • Carotte
    • Brocoli
Où placer la sous-liste ? La sous-liste doit être à l'intérieur du <li>, pas entre deux <li>. Sinon, elle sort de la structure. 
<!-- ❌ Mauvais : la sous-liste est en dehors du li -->
<ul>
  <li>Fruits</li>
  <ul>
    <li>Pomme</li>
  </ul>
</ul>

<!-- ✅ Bon : la sous-liste est dans le li parent -->
<ul>
  <li>Fruits
    <ul>
      <li>Pomme</li>
    </ul>
  </li>
</ul>

5 Cas d'usage classiques des listes

Les listes servent partout dans une vraie page. Quelques exemples :

// Menu de navigation d'un site <ul> <li>Accueil</li> <li>Blog</li> <li>Contact</li> </ul> // Étapes d'une recette <ol> <li>Préchauffer le four</li> <li>Préparer la pâte</li> </ol> // Liste de courses <ul> <li>Pain</li> <li>Lait</li> </ul>

D'ailleurs, tu ne t'en rends peut-être pas compte, mais la sidebar de ce cours est une liste <ul> avec des sous-listes <ul>. Va voir dans le code source (Ctrl+U sur cette page) : les menus sont toujours des listes.

6 Les tableaux : <table>

Un tableau sert à présenter des données en grille : un planning, un classement, un catalogue de prix. C'est un outil précis, avec sa propre structure.

<table>

Le conteneur du tableau.

<tr>

Table row — une ligne du tableau.

<th>

Table header — une cellule d'en-tête (gras et centré par défaut).

<td>

Table data — une cellule normale.

<caption>

Le titre du tableau. Se place juste après <table>. 

<table>
  <caption>Emploi du temps du lundi</caption>
  <tr>
    <th>Heure</th>
    <th>Matière</th>
    <th>Salle</th>
  </tr>
  <tr>
    <td>8h00</td>
    <td>Mathématiques</td>
    <td>B12</td>
  </tr>
  <tr>
    <td>10h00</td>
    <td>Histoire</td>
    <td>A03</td>
  </tr>
  <tr>
    <td>14h00</td>
    <td>Français</td>
    <td>C21</td>
  </tr>
</table>
Emploi du temps du lundi
Heure Matière Salle
8h00 Mathématiques B12
10h00 Histoire A03
14h00 Français C21
La première ligne La première ligne d'un tableau contient en général les <th> : ce sont les « titres de colonnes ». Les autres lignes contiennent les <td>, les vraies données.

7 Les tableaux plus complexes : <thead> et <tbody>

On peut (et on devrait) séparer la partie « en-têtes » de la partie « données » avec deux balises de regroupement. C'est plus clair et plus accessible. 

<table>
  <caption>Mes livres préférés</caption>

  <thead>
    <tr>
      <th>Titre</th>
      <th>Auteur</th>
      <th>Année</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Le Petit Prince</td>
      <td>Saint-Exupéry</td>
      <td>1943</td>
    </tr>
    <tr>
      <td>Harry Potter</td>
      <td>J.K. Rowling</td>
      <td>1997</td>
    </tr>
  </tbody>
</table>
Mes livres préférés
Titre Auteur Année
Le Petit Prince Saint-Exupéry 1943
Harry Potter J.K. Rowling 1997

Le <thead> regroupe les en-têtes, le <tbody> les données.

8 Le grand piège : les tableaux ne servent pas à la mise en page

Avant 2010, on utilisait des <table> pour dessiner toute la mise en page des sites : entêtes, colonnes, footers… C'était une très mauvaise idée, mais on n'avait pas le choix. Aujourd'hui, on ne le fait plus.

Pourquoi c'est mauvais ?
  • Accessibilité : un lecteur d'écran annonce « tableau de 3 lignes, 2 colonnes » à une personne malvoyante, alors qu'il n'y a aucune donnée à comprendre.
  • Sémantique : tu mens sur la nature de ton contenu. Un tableau, c'est pour des données.
  • Maintenance : modifier une mise en page en table est un cauchemar.

La règle : on utilise <table> uniquement pour de vraies données tabulaires (planning, catalogue, comparaison, statistiques). Pour la mise en page, on utilise CSS (Flexbox et Grid, qu'on verra plus tard).

9 Récapitulatif : quand utiliser quoi ?

<ul>

Liste sans ordre. Menu, liste de courses, tags, liens… La position de chaque élément n'a pas d'importance.

<ol>

Liste ordonnée. Recette, étapes, classement, top 10… L'ordre porte du sens.

<table>

Données en grille. Planning, prix, statistiques, comparaison de produits. Jamais pour la mise en page.

🎯 Défi — Ta recette structurée

Crée un fichier recette.html dans ton dossier 01-html, avec :

  • Un <h1> : Ma recette de crêpes
  • Un <h2> : Ingrédients, suivi d'une liste non ordonnée (<ul>) avec au moins 5 ingrédients.
  • Un <h2> : Préparation, suivi d'une liste ordonnée (<ol>) avec au moins 5 étapes.
  • Un <h2> : Temps, suivi d'un petit tableau à 2 colonnes : Étape et Durée. Quelques lignes : repos de la pâte 1h, cuisson 2 min par crêpe…
  • Pour aller plus loin : mets un ingrédient avec une sous-liste (par exemple « Épices » avec ses variantes).

💡 Vérifie que le tableau contient bien des <th> sur la première ligne et des <td> ailleurs.

Voir une solution 
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma recette de crêpes</title>
</head>
<body>

  <h1>Ma recette de crêpes</h1>

  <h2>Ingrédients</h2>
  <ul>
    <li>250 g de farine</li>
    <li>4 œufs</li>
    <li>50 cl de lait</li>
    <li>2 cuillères à soupe de sucre</li>
    <li>1 pincée de sel</li>
    <li>Parfums possibles :
      <ul>
        <li>Extrait de vanille</li>
        <li>Zeste de citron</li>
      </ul>
    </li>
  </ul>

  <h2>Préparation</h2>
  <ol>
    <li>Mettre la farine dans un saladier.</li>
    <li>Ajouter les œufs un par un.</li>
    <li>Verser le lait petit à petit en mélangeant.</li>
    <li>Ajouter le sucre et le sel.</li>
    <li>Laisser reposer la pâte 1 heure.</li>
  </ol>

  <h2>Temps</h2>
  <table>
    <tr>
      <th>Étape</th>
      <th>Durée</th>
    </tr>
    <tr><td>Préparation</td><td>10 min</td></tr>
    <tr><td>Repos de la pâte</td><td>1 h</td></tr>
    <tr><td>Cuisson</td><td>2 min par crêpe</td></tr>
  </table>

</body>
</html>
