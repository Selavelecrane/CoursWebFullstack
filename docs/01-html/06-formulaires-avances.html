Module 1 · HTML

Formulaires — champs avancés

Les cases à cocher, les boutons radio, les listes déroulantes, les zones de texte… Plus la validation intégrée qui vérifie la saisie de l'utilisateur sans une ligne de JavaScript. C'est la partie confortable et puissante des formulaires.

1 Les cases à cocher : checkbox

Une case à cocher laisse l'utilisateur sélectionner plusieurs options indépendamment les unes des autres. Comme des interrupteurs. 

<fieldset>
  <legend>Tes langages préférés</legend>

  <label>
    <input type="checkbox" name="html" value="oui">
    HTML
  </label>

  <label>
    <input type="checkbox" name="css" value="oui">
    CSS
  </label>

  <label>
    <input type="checkbox" name="js" value="oui">
    JavaScript
  </label>
</fieldset>
Tes langages préférés

Tu peux cocher autant de cases que tu veux.

Astuce : plusieurs name identiques Ici, les trois cases ont le même name (langages). C'est volontaire : côté serveur, on récupère toutes les valeurs cochées de ce groupe. Si tu veux des cases indépendantes, utilise des name différents.

2 Les boutons radio : radio

Un bouton radio ressemble à une case à cocher, mais avec une règle différente : un seul choix possible dans un groupe. Comme un questionnaire à choix unique. 

<fieldset>
  <legend>Ton niveau en code</legend>

  <label>
    <input type="radio" name="niveau" value="debutant">
    Débutant
  </label>

  <label>
    <input type="radio" name="niveau" value="intermediaire">
    Intermédiaire
  </label>

  <label>
    <input type="radio" name="niveau" value="avance">
    Avancé
  </label>
</fieldset>
Ton niveau en code

Clique sur les trois : un seul reste sélectionné.

La règle du radio Pour qu'un groupe de boutons radio fonctionne (un seul choix à la fois), ils doivent partager le même name. C'est le name qui forme le groupe.

Si tu donnes des name différents, tous les boutons s'activent en même temps.
value : à quoi ça sert ? Le value est la valeur qui sera envoyée au serveur. Pour HTML, on enverra html. Mais à l'écran, l'utilisateur voit « HTML » (le texte du label).

C'est pour ça qu'on met toujours un value en minuscules, court, technique.

3 La liste déroulante : <select>

Le <select> affiche une liste de choix dans un menu déroulant. Chaque option est un <option>. 

<label for="pays">Ton pays</label>
<select id="pays" name="pays">
  <option value="">— Choisis —</option>
  <option value="fr">France</option>
  <option value="be">Belgique</option>
  <option value="ch">Suisse</option>
  <option value="ca">Canada</option>
</select>
<select>

Le conteneur de la liste déroulante.

<option>

Une option parmi les choix. Le value est ce qui est envoyé au serveur ; le texte entre les balises est ce qui est affiché.

selected

Attribut optionnel sur une <option> pour la pré-sélectionner au chargement.

<optgroup>

Permet de regrouper des options par catégorie, avec un label. Utile quand il y a beaucoup de choix.

Le truc du « — Choisis — » On met souvent une première option vide (ou « Choisis ») pour que l'utilisateur doive sélectionner activement quelque chose. Sinon, la première valeur est choisie par défaut, sans que l'utilisateur s'en rende compte.

4 La zone de texte : <textarea>

Pour un long message (commentaire, biographie, description), le champ d'une ligne ne suffit pas. On utilise <textarea>. 

<label for="message">Ton message</label>
<textarea id="message"
          name="message"
          rows="5"
          placeholder="Écris ici…"></textarea>

La hauteur se règle avec rows="5" (5 lignes visibles).

Particularité du <textarea> Contrairement à l'input, ce n'est pas une balise auto-fermante. On la ferme avec </textarea>. Ne pas oublier !

5 Grouper les champs : <fieldset> et <legend>

Quand un formulaire commence à avoir beaucoup de champs, on les regroupe avec <fieldset> et on donne un titre au groupe avec <legend>. Visuellement, ça dessine un cadre.

<fieldset>

Le conteneur du groupe. Dessine un cadre autour de ses champs.

<legend>

Le titre du groupe. Le navigateur le place dans le bord supérieur du cadre. 

<form>
  <fieldset>
    <legend>Tes infos</legend>

    <label for="nom">Nom</label>
    <input type="text" id="nom" name="nom">

    <label for="prenom">Prénom</label>
    <input type="text" id="prenom" name="prenom">
  </fieldset>

  <fieldset>
    <legend>Ton compte</legend>

    <label for="email2">Email</label>
    <input type="email" id="email2" name="email2">

    <label for="mdp2">Mot de passe</label>
    <input type="password" id="mdp2" name="mdp2">
  </fieldset>
</form>
Tes infos
Ton compte
Un fieldset = un thème Infos personnelles, Adresse de livraison, Paiement… Un formulaire long est toujours découpé en sections. Ça aide l'utilisateur à ne pas se perdre, et c'est essentiel pour l'accessibilité.

6 La validation intégrée : le HTML qui vérifie tout seul

Le HTML moderne peut vérifier la saisie de l'utilisateur sans JavaScript. Il suffit d'ajouter un attribut au champ.

Attribut Ce qu'il vérifie
required Le champ doit être rempli. Sinon, le navigateur bloque l'envoi.
minlength="3" Au moins 3 caractères.
maxlength="20" Au plus 20 caractères.
min="1" / max="100" Pour les nombres : valeur minimale / maximale.
pattern="..." Une expression régulière que la valeur doit respecter. 
<form>
  <label for="pseudo3">Pseudo (3 à 15 caractères)</label>
  <input type="text"
         id="pseudo3"
         name="pseudo3"
         required
         minlength="3"
         maxlength="15">

  <label for="age3">Âge (entre 5 et 120)</label>
  <input type="number"
         id="age3"
         name="age3"
         min="5"
         max="120">

  <button type="submit">Envoyer</button>
</form>

💡 Essaie de cliquer sur « Envoyer » sans remplir le pseudo.

Essaie vraiment ! Clique sur « Envoyer » avec le pseudo vide : le navigateur affiche une bulle « Veuillez remplir ce champ ». Tape un pseudo d'une seule lettre : il refuse aussi. Tape un pseudo de 3 lettres minimum : là ça passe.

Et tu n'as écrit aucun JavaScript. C'est ça, la validation HTML5.
Attention, ce n'est pas suffisant La validation HTML est côté client : elle aide l'utilisateur, mais un petit malin peut la contourner (en désactivant JavaScript, ou en envoyant une requête directe). La vraie validation se fera côté serveur (en PHP), plus tard dans le cours. Les deux se complètent : HTML pour l'expérience, serveur pour la sécurité.

7 Le grand formulaire : on met tout ensemble

Voici un formulaire complet qui combine tout ce qu'on a vu dans les deux chapitres. 

<form>
  <fieldset>
    <legend>Tes infos</legend>

    <label for="pseudo4">Pseudo</label>
    <input type="text" id="pseudo4" name="pseudo"
           required minlength="3">

    <label for="email4">Email</label>
    <input type="email" id="email4" name="email" required>

    <label for="pays4">Pays</label>
    <select id="pays4" name="pays" required>
      <option value="">— Choisis —</option>
      <option value="fr">France</option>
      <option value="be">Belgique</option>
    </select>
  </fieldset>

  <fieldset>
    <legend>Ton niveau</legend>

    <label>
      <input type="radio" name="niveau" value="debutant">
      Débutant
    </label>

    <label>
      <input type="radio" name="niveau" value="avance">
      Avancé
    </label>
  </fieldset>

  <fieldset>
    <legend>Tes intérêts</legend>

    <label>
      <input type="checkbox" name="interets" value="web">
      Web
    </label>

    <label>
      <input type="checkbox" name="interets" value="jeux">
      Jeux vidéo
    </label>

    <label>
      <input type="checkbox" name="interets" value="musique">
      Musique
    </label>
  </fieldset>

  <label for="bio">Parle-nous de toi</label>
  <textarea id="bio" name="bio" rows="4"></textarea>

  <button type="submit">Envoyer</button>
</form>

🎯 Défi — Formulaire de contact complet

Crée un fichier contact.html dans ton dossier 01-html, avec :

  • Un <h1> : Nous contacter
  • Un <p> de présentation.
  • Un formulaire contenant deux <fieldset> :
    • Fieldset 1 : « Vos coordonnées »
      nom (text, required), email (email, required), téléphone (tel, optionnel)
    • Fieldset 2 : « Votre demande »
      Un select « Sujet » avec 3 options (Question, Suggestion, Bug), une série de 3 boutons radio « Urgence » (Basse, Moyenne, Haute), et un textarea « Votre message » (required)
  • Un bouton « Envoyer ma demande ».

💡 Chaque champ doit avoir : type, id, name, et un <label for="...">. Utilise la validation HTML (required, minlength) sur les champs importants.

Voir une solution 
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Contact</title>
</head>
<body>

  <h1>Nous contacter</h1>
  <p>Remplis le formulaire, on te répond sous 24h.</p>

  <form>
    <fieldset>
      <legend>Vos coordonnées</legend>

      <label for="nom">Nom</label>
      <input type="text" id="nom" name="nom"
             required minlength="2">

      <label for="email">Email</label>
      <input type="email" id="email" name="email" required>

      <label for="tel">Téléphone (optionnel)</label>
      <input type="tel" id="tel" name="tel">
    </fieldset>

    <fieldset>
      <legend>Votre demande</legend>

      <label for="sujet">Sujet</label>
      <select id="sujet" name="sujet" required>
        <option value="">— Choisis —</option>
        <option value="question">Question</option>
        <option value="suggestion">Suggestion</option>
        <option value="bug">Bug</option>
      </select>

      <p>Urgence :</p>
      <label>
        <input type="radio" name="urgence" value="basse" checked>
        Basse
      </label>
      <label>
        <input type="radio" name="urgence" value="moyenne">
        Moyenne
      </label>
      <label>
        <input type="radio" name="urgence" value="haute">
        Haute
      </label>

      <label for="message">Votre message</label>
      <textarea id="message" name="message"
                rows="5" required></textarea>
    </fieldset>

    <button type="submit">Envoyer ma demande</button>
  </form>

</body>
</html>
