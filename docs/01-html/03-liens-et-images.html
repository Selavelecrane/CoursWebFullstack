Module 1 · HTML

Liens et images

Sans liens, le web ne serait pas un web — juste des pages isolées. Sans images, il serait bien triste. Aujourd'hui, on apprend les deux, et on découvre au passage une notion fondamentale : les attributs.

1 Les attributs : la nouveauté du jour

Jusqu'ici, on a écrit des balises seules : <p>, <h1>… Une balise, ça dit ce que c'est. Mais ça ne dit pas comment ni avec quoi.

Pour donner des précisions à une balise, on utilise des attributs. Un attribut se place à l'intérieur de la balise d'ouverture, et s'écrit toujours nom="valeur".

<abalise hrefnom =égal "https://..."valeur >fin

Un attribut, c'est toujours : nom="valeur" — entre guillemets.

La formule magique Balise sans attribut : <p>Bonjour</p>
Balise avec attribut : <a href="...">Clique ici</a>

On peut mettre plusieurs attributs dans la même balise, séparés par des espaces.

2 Créer un lien : <a>

La balise <a> (pour anchor, « ancre ») crée un lien cliquable. Son attribut obligatoire est href (hypertext reference) : c'est l'adresse vers laquelle le lien mène. 

<a href="https://fr.wikipedia.org">Visiter Wikipédia</a>
Visiter Wikipédia

Le texte entre les balises devient cliquable. Le navigateur le souligne automatiquement.

Le texte du lien compte Le texte entre <a> et </a> est ce que l'utilisateur lit et clique. Évite « cliquez ici » : préfère un texte descriptif.

❌ <a href="...">Cliquez ici</a>
✅ <a href="...">Voir la documentation CSS</a>

3 Trois types de liens à connaître

<a href="https://...">

Lien externe. Mène vers un autre site. L'URL complète commence par https://. On dit aussi « lien absolu ».

<a href="page.html">

Lien interne. Mène vers une autre page du même site. On utilise un chemin relatif : juste le nom du fichier s'il est dans le même dossier.

<a href="#section">

Ancre. Mène vers une partie de la page actuelle. Le # devant un identifiant fait défiler jusqu'à l'élément qui a cet id. 

<!-- Lien externe (vers un autre site) -->
<a href="https://developer.mozilla.org">MDN Web Docs</a>

<!-- Lien interne (vers une page du même site) -->
<a href="contact.html">Me contacter</a>

<!-- Lien vers un dossier parent -->
<a href="../index.html">Retour à l'accueil</a>

<!-- Ancre (vers une section de cette page) -->
<a href="#bas-de-page">Aller en bas</a>
MDN Web Docs (externe) Me contacter (interne) Retour à l'accueil (interne) Aller en bas (ancre)

Seul le lien externe est vraiment cliquable ici (les autres pages n'existent pas encore dans cette démo).

4 Afficher une image : <img>

La balise <img> est auto-fermante : pas de balise de fermeture. Elle a besoin de deux attributs :

src="..."

La source de l'image. Le chemin vers le fichier image. Comme pour href, on peut utiliser une URL absolue ou un chemin relatif.

alt="..."

Le texte alternatif. Décrit l'image si elle ne s'affiche pas. Obligatoire : essentiel pour l'accessibilité (lecteurs d'écran pour malvoyants) et si l'image met du temps à charger. 

<img src="https://picsum.photos/id/1015/300/200"
     alt="Un paysage de montagne avec un lac">
L'attribut alt n'est pas optionnel Un site sans alt est un site inaccessible pour des millions de personnes qui utilisent un lecteur d'écran. C'est la bonne pratique la plus simple à adopter et la plus importante. Prends l'habitude dès maintenant : toujours un alt.

5 L'utilité de alt en direct

Regarde ce qui se passe quand une image ne s'affiche pas. À gauche, sans alt. À droite, avec un alt. La différence est flagrante.

❌ Sans alt
✅ Avec alt

Avec un alt, l'utilisateur comprend ce qu'il aurait dû voir. C'est aussi ce que lit un lecteur d'écran pour une personne malvoyante. Sans alt, elle n'a littéralement aucune idée de ce qui est affiché.

Comment écrire un bon alt Décris ce que montre l'image en une phrase courte.

❌ alt="image" — inutile
❌ alt="chat" — trop vague
✅ alt="Un chat roux allongé sur un canapé bleu"

Exception : si l'image est purement décorative (une fioriture, un motif), on met alt="" (vide) pour que le lecteur d'écran l'ignore.

6 Chemins relatifs vs absolus

Que ce soit pour un lien (href) ou une image (src), il existe deux façons d'indiquer l'emplacement d'une ressource.

https://site.com/img.jpg

URL absolue. Le chemin complet, avec le domaine. Fonctionne partout, même si tu copies le lien ailleurs. Utilisée pour les liens externes.

images/chat.jpg

Chemin relatif. Relatif à l'emplacement du fichier HTML actuel. Utilisé pour toutes les ressources du même site.

Voici comment les chemins relatifs fonctionnent :

mon-site/ ├── index.html ← la page ├── images/ │ └── chat.jpg ← l'image └── pages/ └── contact.html ← une autre page

Depuis index.html :

  • src="images/chat.jpg" → depuis le dossier courant
  • href="pages/contact.html" → descend dans le sous-dossier

Depuis pages/contact.html :

  • src="../images/chat.jpg" → .. remonte d'un dossier
  • href="../index.html" → remonte puis va à la page d'accueil
Les 3 symboles à retenir . = le dossier courant
.. = le dossier parent (un cran au-dessus)
/ = la racine du site

7 Mettre tout ensemble

Voici une page qui combine tout ce qu'on a vu :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Mes liens utiles</title>
</head>
<body>

  <h1>Mes liens et images</h1>

  <h2>Sites que j'aime</h2>
  <p>
    Je consulte souvent
    <a href="https://developer.mozilla.org">MDN Web Docs</a>
    pour apprendre.
  </p>

  <h2>Mon animal préféré</h2>
  <img src="https://picsum.photos/id/237/200/150"
       alt="Un petit chien noir aux yeux brillants">

  <p>
    Et si tu veux
    <a href="#top">revenir en haut</a>,
    c'est ici.
  </p>

</body>
</html>

Crée un fichier liens.html dans ton dossier 01-html, avec :

  • Un <h1> : Mes sites préférés
  • Un <p> qui présente la page.
  • Une <h2> : Pour apprendre
  • Un <p> contenant 3 liens externes vers tes sites préférés (Wikipédia, MDN, YouTube… ce que tu veux). Chaque lien doit avoir un texte clair (pas « cliquez ici »).
  • Une <h2> : Une image
  • Une image avec <img> (tu peux prendre une URL de https://picsum.photos), avec un alt bien rédigé.
  • Un lien « Retour en haut » avec <a href="#top">.

💡 Teste à la fois les liens externes et l'image. Vérifie qu'aucune image ne s'affiche « cassée » (carré gris avec un texte bizarre).

  <meta charset="UTF-8">

  <p>
    Je consulte
    <a href="https://developer.mozilla.org">MDN Web Docs</a>

  </p>

    Pour les vidéos, j'aime bien
    <a href="https://www.youtube.com">YouTube</a>.
  </p>

    <a href="#top">Retour en haut de la page</a>
  </p>

</body>
</html>
