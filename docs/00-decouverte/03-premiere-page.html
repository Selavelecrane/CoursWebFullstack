Module 0 · Découverte

Ta première page web

Le moment est arrivé. Tu vas écrire ta toute première page HTML, la voir s'afficher dans ton navigateur, et comprendre ce que chaque ligne fait. Rien de magique : juste de la logique.

1 Créer le fichier

On va créer un fichier qui s'appellera index.html. Le nom index est spécial : c'est le fichier que le navigateur ouvre par défaut quand on visite un dossier. Prends l'habitude, on l'utilisera tout le temps.

Dans VS Code, ouvre ton dossier 00-decouverte

Tu dois le voir dans la barre latérale à gauche. Clique dessus pour l'ouvrir.

Crée un nouveau fichier

Fais un clic droit sur le dossier 00-decouverte → New File. Nomme-le exactement index.html.

Un fichier vide s'ouvre

La zone de droite est vide, avec un curseur qui clignote. C'est ici que tu vas écrire. Ne tape rien pour l'instant, lis d'abord la suite.

2 Comprendre une page HTML

Une page HTML, c'est une boîte avec des boîtes dedans. Chaque boîte est délimitée par une balise (un mot entre chevrons < >).

Une balise fonctionne toujours par paire :

<h1>

La balise d'ouverture. Elle dit : « je commence un titre principal ».

Bonjour

Le contenu. C'est le texte qui apparaîtra à l'écran.

</h1>

La balise de fermeture. Le slash / indique qu'on ferme la balise. Elle dit : « le titre est fini ».

À retenir <h1> ouvre, </h1> ferme. Tout ce qui est entre les deux est le contenu de la balise.

Une page HTML complète, c'est un assemblage de plusieurs balises qui s'emboîtent comme des poupées russes.

3 Le squelette d'une page

Tape exactement ceci dans ton fichier index.html. Ne saute aucune ligne. Ce squelette est toujours le même pour toutes les pages web du monde. 

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma première page</title>
</head>
<body>
  <h1>Bonjour le monde !</h1>
  <p>Ceci est ma toute première page web.</p>
</body>
</html>

Bonjour le monde !

Ceci est ma toute première page web.

Voici ce que le navigateur affichera.

Sauvegarde avec Ctrl + S. Sans sauvegarde, rien ne se passe.

4 Ce que chaque ligne veut dire

Reprenons le squelette ligne par ligne. Aucune ligne n'est là par hasard.

<!DOCTYPE html>

Dit au navigateur : « Ceci est une page HTML moderne ». Cette ligne est obligatoire et toujours la première.

<html lang="fr">

La balise racine. Tout est dedans. Le lang="fr" indique que la page est en français (utile pour les moteurs de recherche et la synthèse vocale).

<head>

La tête de la page. Ce qu'on met ici n'apparaît pas à l'écran. Ce sont des informations sur la page.

<meta charset="UTF-8">

Dit au navigateur comment décoder les caractères. Sans ça, les accents (é, à, ç) s'affichent comme des symboles bizarres.

<title>…</title>

Le titre de l'onglet du navigateur. Regarde en haut de ton navigateur : c'est ce que tu vois écrit sur l'onglet.

<body>

Le corps de la page. Tout ce qui s'affiche à l'écran est ici.

<h1>…</h1>

Un titre de niveau 1. Il en existe 6 : de h1 (le plus grand) à h6 (le plus petit).

<p>…</p>

Un paragraphe. Le texte normal. C'est la balise la plus utilisée du HTML.

Le cerveau retient mieux avec une image Imagine une page comme un être humain :
  • <head> = la tête — invisible, mais elle contient les informations (le titre, la langue, les réglages).
  • <body> = le corps — tout ce qu'on voit.

5 Voir le résultat dans ton navigateur

Deux méthodes. La première est plus simple, la seconde plus confortable.

Méthode simple : ouvrir directement

Dans VS Code, fais un clic droit sur index.html → Reveal in File Manager (ou l'équivalent). Double-clique sur le fichier. Il s'ouvre dans ton navigateur par défaut.

Méthode pro : Live Server

Dans VS Code, fais un clic droit sur index.html → Open with Live Server. Le navigateur s'ouvre automatiquement.

À partir de maintenant, chaque fois que tu sauvegardes (Ctrl + S), la page se recharge toute seule. Essaie : modifie le texte de ton <h1>, sauvegarde, regarde le navigateur se mettre à jour.

Le moment magique Ce que tu as écrit dans un fichier apparaît sur ton écran. C'est exactement ce que fait un développeur toute la journée. Bravo, tu viens d'écrire ta première page web.

6 Expérimente

La meilleure façon d'apprendre, c'est de casser des choses. Essaie ces trois modifications, une par une, en sauvegardant à chaque fois : 

<body>
  <h1>Bonjour le monde !</h1>
  <p>Ceci est ma toute première page web.</p>

  <h2>Ce que je vais apprendre</h2>
  <p>Du HTML, du CSS et du JavaScript.</p>

  <h2>Pourquoi ?</h2>
  <p>Parce que je veux créer mes propres sites.</p>
</body>

Bonjour le monde !

Ceci est ma toute première page web.

Ce que je vais apprendre

Du HTML, du CSS et du JavaScript.

Pourquoi ?

Parce que je veux créer mes propres sites.

Tu vois la différence entre <h1> et <h2> ? Le titre h1 est plus gros. Il existe 6 niveaux de titres : h1, h2, h3, h4, h5, h6.

Règle d'or Sur une page, on met un seul h1. Ensuite autant de h2, h3… que nécessaire. Le h1, c'est le titre principal de la page.

🎯 Défi — Ta carte de présentation

Crée une nouvelle page moi.html dans ton dossier 00-decouverte avec :

  • Un <h1> avec ton prénom.
  • Un <h2> qui dit « Qui je suis ».
  • Un <p> qui te décrit en 2 phrases.
  • Un <h2> qui dit « Ce que j'aime ».
  • Un <p> avec 3 choses que tu aimes.
  • Un <h2> qui dit « Mon objectif ».
  • Un <p> qui explique pourquoi tu apprends le web.
