Installer ses outils

Un bon artisan a de bons outils. On installe ici les deux seuls dont tu as besoin pour commencer : un éditeur de code et une extension qui recharge ton navigateur tout seul. 15 minutes, pas plus.

1 Les outils du développeur

Un développeur web a besoin d'exactement deux outils pour commencer :

  • Un éditeur de code — comme un traitement de texte, mais spécialement conçu pour écrire du code. Il colore les mots, repère les erreurs, t'aide à taper.
  • Un navigateur web — Chrome, Firefox, Safari… Tu en as déjà un. C'est lui qui va afficher ton travail.

Et c'est tout. Pas besoin de serveur, pas besoin d'installer quoi que ce soit d'autre pour l'instant.

Une note pour plus tard On ajoutera Git plus tard, quand on mettra ton code sur GitHub. Pour l'instant, on se concentre sur l'essentiel.

2 Installer VS Code

L'éditeur qu'on va utiliser s'appelle Visual Studio Code (ou « VS Code »). C'est gratuit, utilisé par des millions de développeurs, et il existe pour Linux, macOS et Windows.

Ouvre un terminal

Sur Fedora, tu peux le trouver dans le menu des applications (cherche « Terminal ») ou l'ouvrir avec le raccourci Ctrl + Alt + T.

Installe VS Code

Copie-colle cette commande dans le terminal :

sudo dnf install code

Si Fedora te dit que le paquet n'existe pas, essaie via Flatpak :

flatpak install flathub com.visualstudio.code

Lance VS Code

Tape code dans le terminal, ou cherche « Code » dans le menu des applications. Une fenêtre s'ouvre : bienvenue !

Si une fenêtre sombre s'affiche avec un menu à gauche, c'est gagné.

3 Installer l'extension Live Server

Live Server est une extension de VS Code. Son travail : recharger automatiquement ton navigateur dès que tu sauvegardes un fichier. Tu vas voir, ça change la vie.

Ouvre le panneau des extensions

Dans VS Code, clique sur l'icône carrés empilés dans la barre de gauche (ou Ctrl + Shift + X).

Cherche « Live Server »

Tape Live Server dans la barre de recherche. Le premier résultat est celui de Ritwick Dey — clique sur Install.

Vérifie l'installation

Une fois installée, l'extension apparaît dans la liste. Tu n'as plus rien à faire, elle est prête.

Comment on s'en sert Plus tard, dans un fichier HTML, tu verras en bas à droite de VS Code un petit bouton « Go Live ». Un clic → ton navigateur s'ouvre sur ta page. À chaque sauvegarde (Ctrl + S), la page se met à jour automatiquement.

4 Créer ton dossier de travail

On va tout ranger dans un seul dossier. C'est important : ne mets pas tes fichiers n'importe où. Ton « atelier » doit être propre.

Dans le terminal, crée ton dossier de travail :

mkdir ~/cours-web
cd ~/cours-web

Puis ouvre ce dossier dans VS Code :

code .

Le . signifie « le dossier courant ». VS Code s'ouvre et affiche ton dossier vide à gauche.

À quoi ressemblera ton dossier à la fin du cours Ne t'inquiète pas si tu ne comprends pas tout, c'est juste pour te donner une vision :
cours-web/ ├── 00-decouverte/ ← tu es ici ├── 01-html/ ← bientôt ├── 02-css/ ├── 03-javascript/ └── 04-projets/

Pour l'instant, on va juste créer un dossier 00-decouverte. Dans VS Code :

  • Fais un clic droit dans la zone de gauche (là où il n'y a rien)
  • Choisis New Folder
  • Nomme-le 00-decouverte

5 Les raccourcis à connaître

Il y a 5 raccourcis qui vont te servir tous les jours. Prends 30 secondes pour les mémoriser :

  • Ctrl + S → Sauvegarder. À faire après chaque modification. Si tu ne sauvegardes pas, rien ne change dans le navigateur.
  • Ctrl + Z → Annuler. Ton meilleur ami.
  • Ctrl + Shift + Z → Refaire (l'inverse d'annuler).
  • Ctrl + F → Chercher dans le fichier ouvert.
  • Ctrl + B → Afficher / cacher la barre latérale.
La règle d'or Sauvegarde toujours avant de regarder le navigateur. 90 % des « ça ne marche pas » chez les débutants viennent d'un fichier non sauvegardé. Tu verras, on l'a tous fait.
