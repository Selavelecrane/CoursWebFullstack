Module 2 · CSS

Les sélecteurs CSS

Le CSS sert à styliser le HTML. Mais avant de styliser, il faut savoir cibler — dire à quoi une règle s'applique. C'est le rôle des sélecteurs : la fondation de tout CSS.

1 Pourquoi CSS existe ?

Tu l'as vu : le HTML seul donne des pages très moches. Le texte en Times New Roman, en noir, collé aux bords. C'est normal — HTML ne décrit que le sens, pas l'apparence.

Le CSS (Cascading Style Sheets — « feuilles de style en cascade ») est un langage séparé, qui dit au navigateur : « ce <h1>, fais-le en rouge, taille 32px, centré ».

HTML seul

Mon titre

Un paragraphe brut.

Times New Roman, noir, sans mise en page.

HTML + CSS

Mon titre

Un paragraphe stylisé.

Couleur, police, taille : tout est décidé.

La règle fondatrice HTML = quoi · CSS = à quoi ça ressemble. Deux langages, deux rôles bien séparés. On ne met jamais de style directement dans le HTML (sauf cas très précis qu'on verra).

2 Les 3 façons de lier du CSS à du HTML

Il existe trois méthodes pour appliquer du CSS à une page. On utilise surtout la 3ᵉ.

1 Inline (dans la balise)

Directement dans l'attribut style d'un élément. À éviter : mélange HTML et CSS, impossible à réutiliser. 

<h1 style="color: red; font-size: 32px;">Mon titre</h1>

2 Interne (dans le <head>)

Dans une balise <style>, au début de la page. Pratique pour les pages isolées, mais pas réutilisable sur plusieurs pages. 

<head>
  <style>
    h1 {
      color: red;
    }
  </style>
</head>

3 Externe (fichier séparé) ✅

Dans un fichier .css séparé, lié par une balise <link>. C'est la méthode professionnelle : un seul fichier de style pour tout un site. 

<head>
  <link rel="stylesheet" href="style.css">
</head>
À retenir À partir de maintenant, tu utiliseras la méthode externe. Un fichier style.css à côté de ton index.html, lié par <link rel="stylesheet" href="style.css">. C'est ça que font tous les sites pro.

3 Anatomie d'une règle CSS

Une règle CSS a toujours la même forme : un sélecteur suivi d'un bloc entre accolades, contenant des déclarations.

h1sélecteur {
colorpropriété : redvaleur ;
font-sizepropriété : 32pxvaleur ;
}
sélecteur

À quoi la règle s'applique. C'est la partie la plus importante — si ton sélecteur est mauvais, aucun style ne s'applique.

{ }

Le bloc. Contient toutes les propriétés à appliquer.

propriété: valeur;

Une déclaration. Chaque ligne modifie une propriété. Le ; à la fin est obligatoire (sauf sur la dernière, mais prends l'habitude de le mettre).

Syntaxe à retenir sélecteur { propriété: valeur; }
Avec un espace après le :, et un ; après chaque déclaration.

4 Sélecteur d'élément

Le plus simple : cibler toutes les balises d'un type. Écrire p applique le style à tous les paragraphes de la page. 

.el-demo p {
  color: #db2777;
  font-weight: 700;
}
.el-demo h2 {
  color: #0ea5e9;
  border-bottom: 2px solid #0ea5e9;
  padding-bottom: 4px;
}

Un titre

Un paragraphe devient rose et gras.

Un autre paragraphe aussi.

Limite du sélecteur d'élément Il est trop large : il touche tous les p, partout. Si tu veux styler uniquement certains paragraphes, il faut autre chose.

5 Sélecteur de classe (le plus utilisé)

Une classe est une étiquette qu'on met dans le HTML avec l'attribut class="...". Plusieurs éléments peuvent partager la même classe. En CSS, on la cible avec un point devant : .ma-classe. 

.classe-demo .important {
  color: #dc2626;
  font-weight: 700;
}
.classe-demo .note {
  color: #6b7280;
  font-style: italic;
  font-size: .9em;
}
<p class="important">Ce paragraphe est important.</p>
<p>Ce paragraphe est normal.</p>
<p class="note">Ce paragraphe est une note.</p>

Ce paragraphe est important.

Ce paragraphe est normal.

Ce paragraphe est une note.

Pourquoi les classes sont géniales
  • Réutilisables : une classe définie une fois s'applique partout où elle est posée.
  • Précises : tu cibles exactement ce que tu veux.
  • Combinables : un élément peut avoir plusieurs classes (class="important note").

Convention de nommage : les classes sont en minuscules, sans accents, avec des tirets pour séparer les mots (mon-super-paragraphe).

6 Sélecteur d'id (unique)

Un id est comme une classe, mais unique dans la page — un seul élément peut avoir un id donné. On le cible avec un dièse : #mon-id. 

.id-demo #titre-principal {
  color: #7c3aed;
  text-align: center;
  font-size: 1.6em;
}
<h2 id="titre-principal">Mon titre unique</h2>
<h2>Un autre titre</h2>

Mon titre unique

Un autre titre

Classe ou id ? La règle de pro Utilise toujours des classes. Les ids ont deux problèmes :
  • Ils sont trop puissants en spécificité (on verra ça juste après), ce qui rend le CSS difficile à surcharger.
  • Ils ne peuvent pas être réutilisés — tu te retrouves avec du code dupliqué.
Les ids servent surtout à une chose : créer des ancres (<a href="#mon-id">) ou lier un <label> à un <input>.

7 Les sélecteurs combinés

On peut combiner des sélecteurs pour être plus précis.

Sélecteur Signifie
p Tous les paragraphes.
.rouge Tous les éléments avec class="rouge".
p.rouge Les <p> qui ont la classe rouge (pas les <h2 class="rouge">).
* Tous les éléments (le sélecteur universel).
div p Les p qui sont quelque part à l'intérieur d'un div.
div > p Les p qui sont enfants directs d'un div.
p + p Un p qui suit immédiatement un autre p.
a:hover Un lien quand la souris est dessus. 
.comb-demo p {
  background: #f3f4f6;
  padding: 6px 10px;
  border-radius: 6px;
  margin: 4px 0;
  font-size: .92rem;
}
.comb-demo p.hit {
  background: #fef3c7;
  box-shadow: 0 0 0 2px #fbbf24;
}
.comb-demo a {
  color: #0ea5e9;
  text-decoration: underline;
  transition: color .15s;
}
.comb-demo a:hover {
  color: #7c3aed;
  text-decoration: none;
}

Un paragraphe normal.

Ce paragraphe a la classe hit.

Un autre paragraphe.

Passe la souris sur ce lien pour voir l'effet :hover.

Combiner pour être précis Le sélecteur p.hit ne cible que les <p> ayant la classe hit. C'est différent de .hit tout seul, qui toucherait n'importe quel élément avec cette classe.

8 La spécificité (pourquoi mon style ne s'applique pas)

Parfois, un style est écrit… mais ne s'applique pas. C'est presque toujours un problème de spécificité : quand deux règles touchent le même élément, la plus « forte » gagne.

La hiérarchie, du plus faible au plus fort :

  1. Sélecteur d'élément — p, h1… (poids 1)
  2. Sélecteur de classe — .important (poids 10)
  3. Sélecteur d'id — #titre (poids 100)
  4. Style en ligne — style="..." (poids 1000) 
/* Plusieurs règles touchent le même h2 */
.spe-demo h2 {
  color: #22c55e;      /* poids 1+1 = faible */
}
.spe-demo .titre {
  color: #0ea5e9;      /* poids 10 = plus fort */
}
.spe-demo #mon-titre {
  color: #dc2626;      /* poids 100 = le plus fort ! */
}
<h2 id="mon-titre" class="titre">Quelle couleur je vais prendre ?</h2>

Quelle couleur je vais prendre ?

L'id gagne : le titre est rouge, pas bleu, pas vert.

Ce qu'il faut retenir
  • À poids égal, la dernière règle écrite gagne (effet « cascade »).
  • Un id écrase une classe, qui écrase un élément.
  • Le style en ligne écrase presque tout.
  • Pour cette raison, évite les id en CSS : ça rend ton code difficile à modifier.

9 Récap' du chapitre

Les sélecteurs, c'est la grammaire du CSS. Une fois que tu les as, tout devient clair.

Les 4 sélecteurs à connaître par cœur
  • p — sélecteur d'élément (large)
  • .ma-classe — sélecteur de classe (le plus utilisé) ✅
  • #mon-id — sélecteur d'id (à éviter sauf cas précis)
  • p.ma-classe — combinaison (précise)

🎯 Défi — Stylise ta première page

Crée un fichier selecteurs.html dans ton dossier 02-css (à créer), et un fichier style.css à côté.

  • Le HTML contient un <h1>, trois <p>, dont un avec la classe important et un avec la classe astuce.
  • Le <link> vers style.css doit être dans le <head>.
  • Dans le CSS, tu dois avoir :
    • Une règle qui s'applique à tous les paragraphes (couleur, taille, interlignage).
    • Une règle qui s'applique uniquement à .important (en rouge + gras).
    • Une règle qui s'applique uniquement à .astuce (en italique + fond gris).
    • Une règle sur h1 (couleur, alignement, bordure en bas).
Voir une solution 
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Sélecteurs</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Ma première page stylisée</h1>
  <p>Un paragraphe normal.</p>
  <p class="important">Un paragraphe important.</p>
  <p class="astuce">Une petite astuce en note.</p>
</body>
</html>
