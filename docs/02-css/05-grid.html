1.1 Pourquoi CSS Grid ?

Imagine une feuille quadrillée : tu choisis combien de colonnes et de lignes elle a, puis tu poses tes éléments dedans. Voilà CSS Grid. C'est le premier système de CSS pensé pour la mise en page en deux dimensions (horizontal et vertical en même temps).

Flexbox = 1 dimension

Aligne des éléments sur un seul axe à la fois. Idéal pour une barre de navigation, un groupe de boutons.

Grid = 2 dimensions

Contrôle lignes et colonnes ensemble. Idéal pour la structure d'une page, une galerie, un dashboard.

Règle simple Grid pour la structure, Flexbox pour le contenu à l'intérieur des blocs.

4.3 subgrid : aligner les cartes

Le problème Trois cartes côte à côte avec un titre, un texte et un bouton. Les titres ont des hauteurs différentes → les boutons ne s'alignent pas. subgrid résout ça : la carte hérite des rangées du parent. 
.cartes {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto auto auto;
  gap: 0 10px;
}
.carte {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
}

Court

Un texte bref.

Un titre bien plus long

Un texte beaucoup plus long qui occupe plusieurs lignes.

Moyen

Un texte de longueur moyenne.

Bascule subgrid / none : les boutons s'alignent ou pas.

À retenir subgrid n'est pas un inherit — c'est une relation vivante : l'enfant pointe sur les pistes du parent. Si le parent change, l'enfant suit.

4.7 Piège du 1fr qui déborde

À connaître 1fr est en réalité minmax(auto, 1fr) : la colonne refuse de rétrécir sous son contenu. Solution : minmax(0, 1fr). 
.casse, .ok { display: grid; gap: 8px; }
.casse { grid-template-columns: 1fr 1fr; }
.ok    { grid-template-columns: minmax(0, 1fr) minmax(0, 1fr); }
.ok > * { min-width: 0; overflow: hidden; text-overflow: ellipsis; }
