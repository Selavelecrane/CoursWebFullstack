Couleurs et typographie

Avec ces deux propriétés, tu vas transformer radicalement l'aspect de tes pages. 80 % de l'effet visuel d'un site vient de la couleur et de la police. On apprend les deux aujourd'hui.

1 La couleur du texte : color

La propriété color change la couleur du texte. Elle s'applique à l'élément ciblé et se transmet aux enfants (héritage). 

.color-demo p {
  color: #0ea5e9;
}
.color-demo h2 {
  color: #dc2626;
}

4 Les formats techniques

La même couleur peut s'écrire de plusieurs façons. Voici les 4 formats principaux :

#0ea5e9 Hexadécimal. Le plus courant. Six caractères : rouge, vert, bleu (de 00 à ff).
rgb(14, 165, 233) RGB. Trois nombres de 0 à 255 : R, V, B.
rgba(14, 165, 233, .45) RGBA. Comme RGB + opacité (0 à 1). .45 = 45 % transparent.
hsl(198, 88%, 48%) HSL. Teinte (0-360°), saturation, luminosité. Très intuitif.
Lequel utiliser ? Pour un site pro, on utilise généralement :
  • Hex pour les couleurs opaques (court, universel).
  • rgba() ou hsl() quand on a besoin de transparence.
  • HSL quand on veut ajuster rapidement la luminosité d'une couleur.

5 La police : font-family

font-family définit la police utilisée pour le texte. On donne plusieurs polices par ordre de préférence : si la première n'est pas installée sur l'ordinateur, le navigateur essaie la suivante.

Georgia, serif

Les 3 grandes familles
  • Serif — empattements aux extrémités des lettres (Georgia, Times, Playfair). Classique, élégant.
  • Sans-serif — pas d'empattements (Arial, Helvetica, Space Grotesk). Moderne, lisible à l'écran.
  • Monospace — largeur fixe (Courier, JetBrains Mono). Pour le code, les terminaux.

Toujours terminer la liste par un mot-clé de famille : serif, sans-serif, monospace. C'est le fallback si aucune police de la liste n'existe.

6 La taille du texte : font-size

font-size accepte plusieurs unités. Les plus utilisées :

px

Pixels. Taille fixe, ne change pas selon le contexte. Simple, mais respecte mal les préférences d'accessibilité.

rem

Relative à la taille racine (1rem = 16px par défaut). Recommandée : elle s'adapte si l'utilisateur agrandit sa police dans son navigateur.

em

Relative au parent. 1.5em = 1,5 × la taille du parent. Utile pour des tailles proportionnelles.

%

Comme em, mais en pourcentage.

.size-demo-base { font-size: 16px; }

.size-demo-base .small  { font-size: 0.8rem; }
.size-demo-base .normal { font-size: 1rem; }
.size-demo-base .big    { font-size: 1.5rem; }
.size-demo-base .huge   { font-size: 2rem; }
.8rem Petit texte (12,8 px)
1rem Texte normal (16 px) — la taille de référence
1.5rem Texte plus grand (24 px)
2rem Grand texte (32 px)
Pratique courante On met font-size: 16px; sur body (ou rien, c'est la valeur par défaut), puis on utilise rem partout ailleurs. Comme ça, tout le site s'adapte si l'utilisateur change la taille de base.

7 Le gras et l'italique

font-weight

Graisse de la police. normal (400) ou bold (700). Peut aussi être un nombre de 100 à 900.

font-style

Style de la police. normal ou italic.

text-decoration

Décoration du texte. none (par défaut) ou underline, line-through.

text-align

Alignement horizontal. left, center, right, justify.

line-height

Hauteur de ligne. L'espace vertical entre les lignes. 1.5 est une valeur confortable. 

.txt-demo h2 {
  text-align: center;
  text-decoration: underline;
  color: #7c3aed;
}
.txt-demo .gras {
  font-weight: 700;
}
.txt-demo .italique {
  font-style: italic;
  color: #dc2626;
}
.txt-demo p {
  line-height: 1.8;
  text-align: justify;
}

9 Ajouter une police Google Fonts

Les polices par défaut du navigateur sont… correctes, mais banales. Pour un vrai design, on utilise souvent des polices externes, chargées depuis Google Fonts (gratuit). Voici la méthode en 2 étapes.

<link>

Dans le <head>, on colle un lien vers la police choisie sur fonts.google.com.

font-family

Dans le CSS, on écrit simplement le nom de la police en premier dans la liste. 

<head>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link href="https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;700&display=swap" rel="stylesheet">
</head>
body {
  font-family: 'Playfair Display', serif;
}
Limite-toi à 2-3 polices Une police pour les titres, une pour le texte. C'est tout. Plus de 2-3 polices sur un site = chaos visuel. Et ça ralentit le chargement.

🎯 Défi — Stylise ta carte de visite

Crée carte.html et carte.css dans ton dossier 02-css. La carte doit contenir :

  • Un <h1> avec ton prénom.
  • Un <p> avec ton rôle (ex. « Apprenti développeur »).
  • Un <p> de description.
  • Un lien <a> vers un site que tu aimes.

En CSS, applique :

  • Une couleur de fond à la carte (pas blanche).
  • Une couleur de texte contrastée.
  • Une police Google Fonts pour le h1.
  • Une autre police pour le texte.
  • Une taille de police en rem pour le titre (au moins 2rem).
  • text-align: center sur le titre.
  • line-height: 1.6 sur les paragraphes.
  • Le lien doit avoir color + text-decoration: none + un :hover qui le souligne.
