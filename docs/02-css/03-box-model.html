Module 2 · CSS

Le box model

Chaque élément HTML est une boîte. Cette boîte a quatre zones, qui s'emboîtent comme des poupées russes. Tant que tu n'as pas visualisé ça, tu ne comprends pas la moitié des problèmes de mise en page. Aujourd'hui, on le visualise et on le manipule.

1 Tout est une boîte

Un titre, un paragraphe, une image, un bouton, un lien… tout est une boîte rectangulaire dans le rendu du navigateur. Quand tu ouvres les DevTools (F12) et que tu survoles un élément, tu vois d'ailleurs un rectangle coloré s'afficher.

Cette boîte est composée de quatre zones, du plus interne au plus externe :

CONTENU
content

Le contenu. Le texte ou l'image. Sa taille se règle avec width et height.

padding

La marge intérieure. L'espace entre le contenu et la bordure. Située à l'intérieur de la boîte.

border

La bordure. Le trait qui entoure le padding. Peut être invisible (0).

margin

La marge extérieure. L'espace entre la bordure et les voisins. Située à l'extérieur.

La phrase magique Padding = intérieur. Margin = extérieur.
Retiens ça, et tu ne confondras plus jamais les deux.

2 Le padding

Le padding crée de l'espace à l'intérieur de la boîte, entre le contenu et la bordure. Utile pour « donner de l'air » au contenu sans changer sa taille apparente. 

.pad-demo .box {
  background: #fef3c7;
  border: 2px solid #f59e0b;
  border-radius: 8px;
  margin: .5rem 0;
}
.pad-demo .box.small { padding: 4px; }
.pad-demo .box.medium { padding: 16px; }
.pad-demo .box.big { padding: 32px; }

padding: 4px — collé aux bords padding: 16px — respire padding: 32px — très aéré

Le padding s'écrit de plusieurs façons :

/* 4 valeurs → haut, droite, bas, gauche (dans le sens des aiguilles d'une montre) */
padding: 10px 20px 30px 40px;

/* 3 valeurs → haut, gauche/droite, bas */
padding: 10px 20px 30px;

/* 2 valeurs → haut/bas, gauche/droite */
padding: 10px 20px;

/* 1 valeur → les 4 côtés en même temps */
padding: 16px;

/* Individuellement : */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;
Le sens des valeurs haut → droite → bas → gauche, comme les aiguilles d'une montre.
padding: 10px 20px 30px 40px; = 10 en haut, 20 à droite, 30 en bas, 40 à gauche.

3 La margin

La margin crée de l'espace à l'extérieur, entre la boîte et ses voisines. C'est ce qui « éloigne » les éléments les uns des autres.

Elle s'écrit exactement comme le padding :

/* Mêmes règles que le padding */
margin: 10px;
margin: 10px 20px;
margin-top: 20px;
margin-bottom: 40px;
.margin-demo .box {
  background: #dbeafe;
  border: 2px solid #2563eb;
  border-radius: 8px;
  padding: 10px 14px;
}
.margin-demo .box.top { margin-bottom: 6px; }
.margin-demo .box.middle { margin-bottom: 24px; }
.margin-demo .box.bottom { margin-bottom: 0; }
margin-bottom: 6px
margin-bottom: 24px — plus d'espace en dessous
margin-bottom: 0 — collé
Astuce centre : margin: 0 auto Pour centrer horizontalement un bloc à largeur fixe, on écrit margin: 0 auto;. Le auto répartit équitablement l'espace restant à gauche et à droite.

4 La bordure

La border entoure la boîte, entre le padding et la margin. Elle a trois propriétés qu'on combine dans un raccourci :

border-width

L'épaisseur : 1px, 2px, thin, medium, thick.

border-style

Le style : solid, dashed, dotted, double, none.

border-color

La couleur (n'importe quel format CSS).

/* Raccourci : width style color */
border: 2px solid #38bdf8;

/* Équivalent complet : */
border-width: 2px;
border-style: solid;
border-color: #38bdf8;
.border-demo .box {
  padding: 10px 14px;
  margin: .4rem 0;
  font-size: .92rem;
  border-radius: 6px;
}
.border-demo .b1 { border: 2px solid #0ea5e9; }
.border-demo .b2 { border: 2px dashed #a78bfa; }
.border-demo .b3 { border: 2px dotted #22c55e; }
.border-demo .b4 { border: 4px double #f43f5e; }
border: 2px solid
border: 2px dashed
border: 2px dotted
border: 4px double
border-radius La propriété border-radius: 12px; arrondit les coins d'un élément. border-radius: 50%; transforme un carré en cercle. Indispensable pour les avatars et les boutons modernes.

6 width et height

Ces deux propriétés fixent la taille du contenu (par défaut). Attention, elles acceptent plusieurs unités et pas mal de valeurs particulières :

width: 300px;

Taille fixe. Ne change jamais.

width: 50%;

Pourcentage du parent. S'adapte au redimensionnement.

width: 100%;

Prend toute la largeur disponible du parent.

max-width: 800px;

Largeur maximale. L'élément peut rétrécir, mais ne dépassera jamais 800px.

min-width: 200px;

Largeur minimale. En dessous de 200px, il refuse de rétrécir.

Le combo gagnant max-width: 800px; margin: 0 auto; — c'est le pattern des contenus centrés lisibles. Un article qui ne prend jamais plus de 800px de large, centré sur la page. Simple et efficace.

7 Le piège du siècle : box-sizing

Voici LE piège qui rend fou les débutants. Écoute bien.

Par défaut, quand tu écris width: 200px;, cette largeur concerne uniquement le contenu. Le padding et la border s'ajoutent par-dessus.

Donc si tu écris :

.boite {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}

La largeur totale à l'écran n'est pas 200px, mais :

200 (width) + 20 (pad gauche) + 20 (pad droite) + 5 (border gauche) + 5 (border droite) = 250px

Ça paraît anodin, mais ça casse tout quand tu veux aligner deux colonnes de 50 %.

❌ Sans border-box (défaut)
width: 150px
padding: 10px
border: 3px
total réel : 176px
✅ Avec border-box
width: 150px
padding: 10px
border: 3px
total réel : 150px

La solution ? Une seule ligne de CSS, à mettre au début de chaque projet : 

* {
  box-sizing: border-box;
}
À retenir absolument Avec box-sizing: border-box, quand tu écris width: 200px, c'est 200px au total. Le padding et la border sont déduits à l'intérieur. C'est ce que tout le monde veut, et c'est pour ça que tous les projets mettent cette ligne au début.
Pourquoi c'est le défaut historique ? Parce que le CSS a été créé en 1996, avant qu'on se rende compte que ce comportement était pénible. Aujourd'hui on ne peut plus changer le défaut (ça casserait des millions de sites). Mais dans les nouveaux projets, on met toujours la règle * { box-sizing: border-box; }.

8 Le margin collapse (bonus)

Il existe un phénomène bizarre en CSS : quand deux marges verticales se touchent, elles fusionnent. Elles ne s'additionnent pas — elles prennent la plus grande.

Bloc 1 — margin-bottom: 30px
espace réel : 50px (pas 80px !)
Bloc 2 — margin-top: 50px

30 + 50 ne font pas 80, mais 50. Le navigateur prend la plus grande des deux marges. Ce phénomène s'appelle le margin collapse.

Ça ne marche que verticalement Le margin collapse s'applique uniquement aux marges verticales (top/bottom) entre éléments adjacents. Les marges horizontales ne fusionnent jamais.

Pas besoin de comprendre tous les cas tordus aujourd'hui. Retiens juste : les marges verticales fusionnent parfois, ne t'étonne pas si l'espace calculé n'est pas exact.

9 Le reset CSS minimal

Chaque navigateur a ses styles par défaut (marges, tailles, polices…). Pour repartir sur des bases propres et identiques partout, on commence souvent ses feuilles de style par un petit « reset » : 

/* Reset minimal recommandé */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: system-ui, sans-serif;
  line-height: 1.6;
}

img {
  max-width: 100%;
  display: block;
}
À mettre au début de TOUS tes projets Ces quelques lignes suppriment les différences entre navigateurs et te donnent une base saine. Le * { box-sizing: border-box; } est non négociable. Le reste, tu peux l'ajuster selon ton projet.
