Module 2 · CSS

Flexbox

Le box model gère une boîte. Flexbox gère plusieurs boîtes : comment les aligner, les répartir, les centrer. C'est le premier vrai système de mise en page du CSS moderne, et tu vas l'utiliser tous les jours.

1 Pourquoi Flexbox ?

Imagine une barre de navigation : un logo à gauche, trois liens à droite, alignés verticalement au centre. Avec les vieilles techniques (floats, position absolute), c'était un cauchemar.

Flexbox est arrivé pour résoudre ça. Une ligne de CSS sur le parent : display: flex;. Et tous les enfants directs deviennent des flex items alignés en ligne. C'est tout.

La règle simple Flexbox = mise en page sur 1 axe (une ligne ou une colonne). Pour du 2D (lignes ET colonnes en même temps), ce sera Grid, au chapitre suivant.

2 Activer Flexbox : display: flex

On met display: flex; sur le parent. Automatiquement :

  • Les enfants s'alignent en ligne (horizontalement).
  • Ils prennent la taille de leur contenu (ne s'étirent plus en pleine largeur).
  • Ils s'alignent en haut par défaut.
.flex-demo {
  display: flex;
}
<div class="flex-demo">
  <div>Un</div>
  <div>Deux</div>
  <div>Trois</div>
</div>

Les 3 boîtes s'alignent en ligne, chacune à la taille de son contenu.

Piège classique display: flex; transforme les enfants directs en flex items. Pas les petits-enfants. Comme pour Grid.

3 Les deux axes

Flexbox raisonne en deux axes. Comprendre ces deux axes, c'est comprendre 90 % de Flexbox.

Axe principal (main axis)

→ la direction dans laquelle les items sont alignés. Par défaut : horizontal.

Axe secondaire (cross axis)

→ perpendiculaire au principal. Par défaut : vertical.

Retiens les 2 propriétés clés
  • justify-content → aligne sur l'axe principal.
  • align-items → aligne sur l'axe secondaire.

Si tu changes flex-direction en column, les axes s'inversent : principal devient vertical, secondaire devient horizontal.

4 La direction : flex-direction

4 valeurs possibles. Par défaut, c'est row (ligne, de gauche à droite).

5 Répartir sur l'axe principal : justify-content

justify-content décide comment les items se répartissent sur l'axe principal. 6 valeurs à connaître :

Valeur Effet
flex-start Alignés au début (défaut).
flex-end Alignés à la fin.
center Centrés.
space-between Espace entre les items. Rien aux bords.
space-around Espace autour de chaque item (demi-espace aux bords).
space-evenly Espaces strictement égaux partout. 
.jc-demo {
  display: flex;
  gap: 10px;
  justify-content: flex-start;
}

Le conteneur est toujours de la même largeur : observe la répartition.

Le plus utilisé : space-between Pour une barre de navigation avec un logo à gauche et un menu à droite, justify-content: space-between; fait exactement ça : les éléments se collent aux extrémités, l'espace libre se met au milieu.

align-items s'occupe de l'axe secondaire. Valeurs principales :

flex-start Alignés au début.
flex-end Alignés à la fin.
center Centrés.
baseline Alignés sur la ligne de base du texte.

7 Espacements : gap

Sur un conteneur flex, gap crée un espace régulier entre les items — exactement comme en Grid. C'est la méthode moderne : plus besoin de marges bricolées. 

.gap-demo {
  display: flex;
  gap: 20px;
}

8 Faire grandir un item : flex et ses comparses

Sur un item (pas sur le parent), on peut décider comment il réagit à l'espace disponible. Trois propriétés :

flex-grow

Capacité à grandir. 0 par défaut (ne grandit pas). 1 = prend sa part de l'espace libre.

flex-shrink

Capacité à rétrécir. 1 par défaut (peut rétrécir). 0 = refuse de rétrécir.

flex-basis

Taille de base. La taille « de départ » de l'item, avant répartition. Par défaut : auto (la taille du contenu).

flex: 1

Raccourci. flex: 1 = flex: 1 1 0 = « prends une part égale de l'espace ». C'est le plus utilisé. 

.fx-demo {
  display: flex;
  gap: 10px;
}
.fx-demo .a { flex: 1; }
.fx-demo .b { flex: 2; }
.fx-demo .c { flex: 1; }
<div class="fx-demo">
  <div class="a">flex: 1</div>
  <div class="b">flex: 2</div>
  <div class="c">flex: 1</div>
</div>
flex: 1
flex: 2
flex: 1

Les valeurs de flex se répartissent comme des parts : 1+2+1 = 4 parts.

Le pattern à retenir : flex: 1 sur les cartes Tu as 3 cartes à mettre côte à côte, toutes de la même largeur ? Mets flex: 1; sur chacune. Elles se partagent l'espace équitablement, et s'adaptent automatiquement à la largeur du conteneur.

9 Cas pratique 1 : la barre de navigation

Le cas d'usage n°1 de Flexbox. Logo à gauche, liens à droite, tout aligné verticalement. 

.navbar-demo {
  display: flex;
  align-items: center;
  gap: 12px;
  justify-content: space-between;
}
.navbar-demo .spacer { flex: 1; }
MonSite Accueil Blog Contact

Le spacer (un <span> vide avec flex: 1) pousse les liens à droite. C'est une technique classique.

Alternative : margin-left: auto Sur le premier lien, tu peux mettre margin-left: auto;. Il sera poussé à droite avec tous les suivants. Plus simple que d'ajouter un spacer.

10 Cas pratique 2 : cartes alignées avec bouton en bas

Le pattern des sites e-commerce : 3 cartes côte à côte, avec un bouton collé en bas de chaque carte. Voici la recette. 

.cards-demo {
  display: flex;
  gap: 12px;
}
.cards-demo .c {
  display: flex;              /* la carte est elle-même un flex */
  flex-direction: column;     /* mais en colonne */
  flex: 1;
}
.cards-demo .c p {
  flex: 1;                    /* le texte prend tout l'espace dispo */
}

Titre court

Un texte bref.

Titre plus long ici

Un texte beaucoup plus long qui va pousser le bouton vers le bas si on n'y prend pas garde.

Moyen

Longueur moyenne.

Les trois boutons sont alignés malgré des textes de tailles différentes.

La recette complète
  1. Le parent : display: flex; gap: 12px;
  2. Chaque carte : display: flex; flex-direction: column; flex: 1;
  3. Dans chaque carte, l'élément à pousser (le texte) : flex: 1;
Ça marche aussi avec <footer>, <ul>, n'importe quoi.

11 Cas pratique 3 : centrage parfait (recette en 2 lignes)

La recette la plus utile de toutes. Tu centres n'importe quoi dans son parent : 

.parent {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
.center-demo {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 180px;
}
Je suis parfaitement centré
Le secret du centrage Pendant 15 ans, les développeurs pleuraient pour centrer verticalement en CSS. Flexbox a résolu ça avec 2 lignes. Aujourd'hui, c'est devenu trivial.

🎯 Défi — Ta page portfolio Flexbox

Crée flex.html + flex.css dans ton dossier 02-css. Ce projet combine tout ce que tu as appris : box model + Flexbox.

  • Un header en display: flex; avec :
    • Ton nom à gauche (en gras).
    • Tes liens « Projets / À propos / Contact » à droite (utilise space-between ou un spacer).
    • Tout aligné verticalement au centre.
  • Un main contenant une section « Mes projets » avec 3 cartes :
    • Le parent des cartes est en display: flex; avec gap: 16px;.
    • Chaque carte est en flex: 1;.
    • Chaque carte est elle-même un flex en colonne, avec un titre, un texte court, et un bouton en bas.
    • Le texte de chaque carte a flex: 1; pour pousser le bouton en bas.
  • Un footer avec un seul paragraphe centré via Flexbox (justify-content: center; sur le footer, ou text-align: center;).
